## 📂 Projets

### ⚡ ZEN Analytics — Plateforme d'analyse de factures d'électricité
API **Django REST** qui analyse des fichiers Excel de facturation d'électricité et génère automatiquement un **rapport Word** (graphiques + commentaires, rédigés au besoin par un LLM).

- Gestion des rôles : `ADMIN` (comptes, contrats, demandes) et `USER` (import, consultation, téléchargement)
- **Architecture à plugins** : chaque type de contrat est un module indépendant (V1 : SONABEL non industriel), ce qui permet d'ajouter facilement de nouveaux contrats
- Les montants proviennent du fichier source : aucune facture n'est recalculée
- Tests automatisés, déploiement Docker

**Technologies :** Python, Django REST Framework, Pandas, Matplotlib, Docker, LLM
